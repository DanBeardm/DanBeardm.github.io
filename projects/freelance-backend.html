Freelance Backend Development

I worked as the main developer and administrator for a Cobblemon-based Minecraft server, building and maintaining multiple Java mods and server-side systems to support gameplay features, automation, balance, and player experience.

The work combined software development, configuration management, debugging, release handling, and live operational support across a real user-facing environment.

Overview

This work went beyond hobby modding. I was building features for a live online community, maintaining stability, responding to issues, and improving systems over time. That meant writing and modifying Java and Kotlin code, working with configuration-driven behaviour in JSON and YAML, debugging from logs and user reports, planning releases, and keeping the server usable for players.
